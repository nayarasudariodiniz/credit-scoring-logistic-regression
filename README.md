Este projeto consiste no desenvolvimento de um modelo preditivo de **Credit Scoring** utilizando **Regressão Logística** para estimar a probabilidade de inadimplência de clientes, abrangendo desde a análise exploratória e o saneamento rigoroso de inconsistências e *outliers* até a tradução e padronização técnica das variáveis financeiras para suporte à decisão em concessão de crédito.
